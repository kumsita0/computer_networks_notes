## Learning Objectives

- Understand how the Internet and computer networks operate.
- Learn application-layer protocols such as HTTP, DNS, and email protocols.
- Understand transport-layer protocols, including TCP and UDP.
- Explore IP addressing, routing, and network-layer operations.
- Study Ethernet, LANs, wireless networks, and network security.
- Strengthen practical networking knowledge and exam readiness.

Each file contains notes for a specific course week or topic. The repository is organized to make it easier to review concepts, prepare for exams, and revisit important networking fundamentals.
